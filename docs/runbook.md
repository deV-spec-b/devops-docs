# Эксплуатация

## Проверка качества

Pylint запускается автоматически при каждом Pull Request и при push в `main`.
Неиспользуемая переменная или неверный импорт приводят к ненулевому коду выхода и блокируют слияние.

## Публикация

Сайт публикуется только из ветки `main` workflow `pages.yml`.
Отказ сборки не затрагивает уже опубликованную версию: GitHub Pages продолжает отдавать предыдущий артефакт.

## Откат

Чтобы вернуть предыдущую версию документации, достаточно отменить merge-коммит или исправить ошибку в новой ветке и влить через Pull Request.
